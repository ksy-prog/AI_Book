## Функциональные требования
Подробное описание того, что должна делать система. Они определяют поведение программного продукта, его функции, сценарии взаимодействия пользователей с интерфейсом и обработку данных

| ID    | Требование                                                                                 |
| ----- | ------------------------------------------------------------------------------------------ |
| FR-01 | Система должна автоматически инициализировать модули MicrophoneService, SilenceDetector, VoskService, LLMService и TTSService при старте сцены                   |
| FR-02 | Система должна отображать информацию о выбранном произведении.                             |
| FR-03 | Пользователь должен иметь возможность начать диалог с ассистентом Никиткой.                |
| FR-04 | Ассистент должен отвечать на вопросы по содержанию выбранного произведения.                |
| FR-05 | Ассистент должен пересказывать сюжет произведения по частям.                               |
| FR-06 | Ассистент должен задавать наводящие вопросы по прочитанному материалу.                     |
| FR-07 | Система должна предоставлять викторины и тесты по содержанию произведения.                 |
| FR-08 | Система должна анализировать результаты тестирования пользователя.                         |
| FR-09 | Система должна определять темы, вызывающие затруднения у пользователя.                     |
| FR-10 | Ассистент должен объяснять непонятные моменты произведения.                                |
| FR-11 | Система должна сохранять историю общения пользователя с ассистентом.                       |
| FR-12 | Система должна вести учёт прогресса прохождения произведения по главам.                    |
| FR-13 | Система должна отображать достижения пользователя.                                         |
| FR-14 | Пользователь должен иметь возможность продолжить обучение с места остановки.               |
| FR-15 | Система должна использовать базу знаний произведения для формирования достоверных ответов. |
| FR-16 | Система должна поддерживать регистрацию и авторизацию пользователей.                       |
| FR-17 | Пользователь должен иметь доступ к своему профилю и статистике обучения.                   |
