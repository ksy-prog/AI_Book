## Функциональные требования
Подробное описание того, что должна делать система. Они определяют поведение программного продукта, его функции, сценарии взаимодействия пользователей с интерфейсом и обработку данных

| ID    | Требование                                                                                 |
| ----- | ------------------------------------------------------------------------------------------ |
| FR-01 | Система должна предоставлять каталог доступных литературных произведений (книг) для выбора                |
| FR-02 | Система должна отображать карточку выбранного произведения с краткой информацией о нем перед началом чтения                |
| FR-03 | Система должна позволять пользователю запускать сценарий изучения произведения (сессию) на основе JSON-файлов сценариев            |
| FR-04 | Система должна поддерживать ручное переключение текстовых блоков и вопросов с помощью элементов интерфейса         |
| FR-05 | Система должна обеспечивать интерактивное общение с AI-ассистентом в формате диалога (голосового или текстового)                            |
| FR-06 | AI-ассистент должен отвечать на вопросы по содержанию произведения, используя локальную базу знаний (модель saiga_llama3)                |
| FR-07 | AI-ассистент должен задавать наводящие и контрольные вопросы по прочитанному материалу после каждого текстового блока                 |
| FR-08 | AI-ассистент должен объяснять непонятные моменты, архаизмы или сложные обороты в тексте                        |
| FR-09 | AI-ассистент должен выдавать мягкие голосовые/текстовые подсказки при длительном молчании пользователя, стимулируя его продолжить чтение                   |
| FR-10 | Система должна проводить интерактивные викторины и тесты по содержанию произведения                             |
| FR-11 | Система должна проверять ответы пользователя в тестах и выводить результаты тестирования на экран                       |
| FR-12 | Система должна анализировать ответы пользователя и выявлять темы или моменты в произведении, вызывающие наибольшие затруднения                  |
| FR-13 | Система должна вести учет прогресса прохождения произведения (по главам и текстовым блокам)                                      |
| FR-14 | Система должна сохранять историю общения пользователя с ассистентом между сессиями               |
| FR-15 | Система должна позволять пользователю возобновлять изучение произведения с места, где оно было прервано |
| FR-16 | Система должна поддерживать геймификацию (отображение достижений и наглядного прогресса на экране)                   |
| FR-17 | Система должна автоматически инициализировать службы микрофона, распознавания речи (STT), генерации текста (LLM) и синтеза речи (TTS) при старте                 |
